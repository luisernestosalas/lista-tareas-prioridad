# Lista de Tareas con Prioridad

Una aplicación web simple y eficiente para gestionar tareas con sistema de prioridades (Alta, Media, Baja). Construida con tecnologías web básicas para máximo rendimiento y compatibilidad.

## 🚀 Demo en Vivo

Prueba la aplicación aquí: [https://lista-tareas-prioridad-hfo4yeguk.vercel.app](https://lista-tareas-prioridad-hfo4yeguk.vercel.app)

## ✨ Características

- ✅ **Gestión completa de tareas**: Crear, editar, eliminar y marcar como completadas
- 🎯 **Sistema de prioridades**: Organiza tus tareas por prioridad (Alta, Media, Baja)
- 🎨 **Indicadores visuales**: Colores distintivos para cada nivel de prioridad
- 💾 **Persistencia local**: Tus tareas se guardan automáticamente en el navegador
- 📱 **Diseño responsivo**: Funciona perfectamente en desktop y móviles
- ⚡ **Sin dependencias**: Construido solo con HTML, CSS y

# Manual de Usuario - Lista de Tareas con Prioridad

## ¿Qué es esta aplicación?

Esta aplicación te ayuda a organizar tus tareas diarias. Puedes crear, editar y eliminar tareas. También puedes marcar qué tareas son más importantes usando niveles de prioridad.

## Cómo acceder

Visita esta dirección en tu navegador:
**https://lista-tareas-prioridad-hfo4yeguk.vercel.app**

## Funciones principales

### 1. Crear una nueva tarea

1. Escribe tu tarea en el campo de texto
2. Selecciona la prioridad:
   - **Alta** - Para tareas muy importantes o urgentes
   - **Media** - Para tareas normales
   - **Baja** - Para tareas menos importantes
3. Haz clic en "Agregar tarea"

### 2. Ver tus tareas

Las tareas se muestran en una lista. Cada tarea tiene:
- El texto de la tarea
- Un color que indica la prioridad:
  - **Rojo** = Prioridad alta
  - **Amarillo** = Prioridad media
  - **Verde** = Prioridad baja

### 3. Marcar tareas como completadas

- Haz clic en la casilla al lado de la tarea
- Las tareas completadas se tac
